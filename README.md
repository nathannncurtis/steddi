# Steddi

iOS navigation app for daily commuters who already know their routes.

Your route, your rules — only rerouted when it actually matters.

## Stack
- Swift / SwiftUI / UIKit (CarPlay)
- Mapbox Navigation SDK v3
- SwiftData
- MVVM architecture
- iOS 17+

## Building
Requires Mapbox access tokens configured in `.netrc` and `Info.plist`. See `docs/SETUP.md`.
